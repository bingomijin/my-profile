GitHub Pages 배포 방법 안내

서버 없이 무료로 이 사이트를 웹에 올리는 순서:

  1. GitHub.com 가입 후 새 저장소(Repository) 생성
  2. 저장소 이름을 username.github.io 로 설정
  3. 다운로드받은 이 파일의 이름을 index.html로 업로드
  4. 노트북의 사진 파일 이름을 profile.jpg로 변경하여 index.html과 같은 폴더(저장소)에 함께 올려주시면 완료됩니다!
